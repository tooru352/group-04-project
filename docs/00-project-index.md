## Finding an artifact quickly

- Requirements/rules: mở mục **Vault**.
- PRD/stories/flows: mở mục **Product**.
- Giao diện tương tác: mở **Prototype entry point**.
- Quyết định và nguồn nghiên cứu: mở mục **Vault** tương ứng.
